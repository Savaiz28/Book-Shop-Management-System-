# 📚 Bookshop Sales and Customer Management System

A desktop-based **Java Swing application** for managing bookstore operations including books, customers, feedback, and sales reports using file handling.

---

## 🚀 Features

### 📖 Book Management
- Add new books
- View book inventory
- Store book details (ID, Title, Author, Price)

### 👤 Customer Management
- Add customer details
- View customer list
- Store customer information (ID, Name, Phone)

### 💬 Feedback System
- Add customer feedback
- View feedback records

### 📊 Sales Report
- Generate basic sales report
- Shows:
  - Total books
  - Total customers
  - Total feedback entries

### 💾 File Handling
- Data stored in `.txt` files
- Automatic saving & loading on startup

---

## 🛠️ Technologies Used

- Java (Core)
- Java Swing (GUI)
- AWT (UI Components)
- File Handling (BufferedReader / FileWriter)
- OOP Concepts
